Visión general

Concepto general

Cómo se conectan las dos estructuras

Árbol binario

Organiza estudiantes por código.

  • Menor: izquierda.
  • Mayor: derecha.
  • Búsqueda jerárquica.

Grafo

Representa dependencias institucionales.

  • Lista de adyacencia.
  • Conexiones no dirigidas.
  • BFS, DFS y rutas.

Integración

Las estructuras se mantienen activas dentro de EduCore y se usan desde sus respectivos menús.

Árbol · Nodo

Nodo y estado inicial

estructuras/arbol_binario.py — líneas 1-15 
class Nodo:
    def __init__(self, codigo, informacion):
        self.codigo = codigo
        self.informacion = informacion
        self.izquierda = None
        self.derecha = None

class ArbolBinario:
    def __init__(self):
        self.raiz = None
        self.cantidad = 0

    def esta_vacio(self):
        return self.raiz is None

Datos del Nodo

  • codigo: clave de búsqueda.
  • informacion: objeto Estudiante.
  • izquierda: códigos menores.
  • derecha: códigos mayores.

Estado inicial

raiz es None. cantidad comienza en cero.

Árbol · Inserción

Insertar un estudiante

estructuras/arbol_binario.py — insertar() 
def insertar(self, codigo, informacion):
    nuevo = Nodo(codigo, informacion)

    if self.raiz is None:
        self.raiz = nuevo
        self.cantidad += 1
        return True

    actual = self.raiz
    while actual is not None:
        if codigo == actual.codigo:
            return False
        if codigo < actual.codigo:
            if actual.izquierda is None:
                actual.izquierda = nuevo
                self.cantidad += 1
                return True
            actual = actual.izquierda
        else:
            if actual.derecha is None:
                actual.derecha = nuevo
                self.cantidad += 1
                return True
            actual = actual.derecha
1

Crea el nodo con código e información.

2

Si no existe raíz, convierte el nodo en raíz.

3

Si el código ya existe, devuelve False.

4

Código menor: izquierda. Código mayor: derecha.

5

Cuando encuentra una posición libre, inserta e incrementa la cantidad.

Árbol · Eliminación

Eliminar un nodo

estructuras/arbol_binario.py — eliminar()

Hoja

Sin hijos. El padre elimina su enlace.

Un hijo

El hijo sustituye directamente al nodo eliminado.

Dos hijos

Busca el sucesor inmediato: derecha y luego todas las izquierdas posibles.

sucesor = actual.derecha
while sucesor.izquierda is not None:
    sucesor = sucesor.izquierda

actual.codigo = sucesor.codigo
actual.informacion = sucesor.informacion
# Elimina físicamente el sucesor y reconecta sus hijos
Árbol · Recorridos

Recorrido inorden y preorden

La recursividad usa automáticamente una pila de llamadas

Inorden

recorrer(nodo.izquierda)
resultado.append(nodo.informacion)
recorrer(nodo.derecha)

Orden: izquierda → nodo → derecha.

Devuelve los códigos ordenados de menor a mayor.

Preorden

resultado.append(nodo.informacion)
recorrer(nodo.izquierda)
recorrer(nodo.derecha)

Orden: nodo → izquierda → derecha.

Visita primero la raíz y después sus ramas.

Árbol · Servicio

Puente entre árbol y estudiante

servicios/gestion_arbol_estudiantes.py 
class GestionArbolEstudiantes:
    def __init__(self):
        self.arbol = ArbolBinario()

    def insertar(self, estudiante):
        return self.arbol.insertar(
            estudiante.codigo, estudiante)

    def buscar(self, codigo):
        return self.arbol.buscar(codigo)

    def eliminar(self, codigo):
        return self.arbol.eliminar(codigo)

Responsabilidad

El servicio conecta objetos Estudiante con ArbolBinario.

  • Crea una instancia del árbol.
  • Usa el código como clave.
  • Delega insertar, buscar y eliminar.
  • Guarda el objeto completo como información.

Grafo · Representación

Grafo de dependencias

{
 "Porteria": ["Biblioteca", "Salones"],

Concepto

La clave representa un vértice.

La lista representa sus vecinos.

Conexión no dirigida: cada vértice guarda al otro como vecino.
Grafo · Operaciones

Conectar y eliminar dependencias

estructuras/grafo.py

Agregar una conexión

self.vertices[origen].append(destino)
self.vertices[destino].append(origen)

Se agregan ambos enlaces, por eso el grafo es no dirigido.

Eliminar una dependencia

for vecino in self.vertices[nombre]:
    self.vertices[vecino].remove(nombre)
del self.vertices[nombre]

Primero elimina los enlaces entrantes y después borra la clave.

Grafo · BFS

Búsqueda en amplitud

servicios/recorridos_grafo.py — bfs() 
visitados = []
cola = Cola()
cola.encolar(inicio)
visitados.append(inicio)

while not cola.esta_vacia():
    actual = cola.desencolar()
    for vecino in consultar_vecinos(actual):
        if vecino not in visitados:
            visitados.append(vecino)
            cola.encolar(vecino)

return visitados

¿Por qué cola?

Una cola es FIFO: el primero que entra es el primero que sale.

Resultado por niveles desde Portería:
Porteria → Biblioteca, Salones → Cafeteria, Enfermeria
Grafo · DFS

Búsqueda en profundidad

servicios/recorridos_grafo.py — dfs() 
visitados = []

def recorrer(actual):
    visitados.append(actual)
    for vecino in consultar_vecinos(actual):
        if vecino not in visitados:
            recorrer(vecino)

recorrer(inicio)
return visitados

¿Por qué recursividad?

Las llamadas pendientes funcionan conceptualmente como una pila LIFO.

  1. Visita el vértice actual.
  2. Toma un vecino nuevo.
  3. Se llama a sí misma.
  4. Cuando termina una rama, vuelve hacia atrás.
Grafo · Ruta

Buscar ruta mínima

servicios/recorridos_grafo.py — buscar_ruta() 
cola.encolar([origen])
visitados = [origen]

while not cola.esta_vacia():
    ruta = cola.desencolar()
    actual = ruta[-1]

    if actual == destino:
        return ruta

    for vecino in consultar_vecinos(actual):
        if vecino not in visitados:
            visitados.append(vecino)
            cola.encolar(ruta + [vecino])

return None

Funcionamiento

La cola guarda rutas completas. BFS descubre primero las rutas con menos conexiones.

Porteria → Enfermeria:
Porteria → Salones → Enfermeria
